# Library Management System

Учебный бэкенд-проект на Go. Консольное и HTTP-приложение для управления библиотекой книг с упором на принципы чистой архитектуры, работу со структурой данных и REST API.

---

## Архитектура и особенности

* **Модульная структура:** Проект разделен на логические пакеты (доменная логика библиотеки, транспортный слой HTTP, работа с ошибками и точкой входа).
* **Управление книгами:** Поддержка добавления, поиска, удаления и изменения информации о книгах.
* **REST API:** Реализован транспортный уровень на базе стандартного пакета `net/http` для взаимодействия с приложением через HTTP-запросы.
* **Обработка ошибок:** Кастомная система обработки ошибок доменного слоя.

---

## Основной функционал

* Добавление новой книги в библиотеку.
* Получение списка всех доступных книг.
* Поиск книг по идентификатору или параметрам.
* Удаление и обновление записей.

---

## Запуск проекта

1. Склонировать репозиторий и перейти в директорию проекта.
2. Запустить приложение:
   ```bash
   go run main.go
   ```
## Структура проекта:
```
├── http/          # HTTP-хендлеры, маршрутизация и DTO
├── library/       # Доменная модель книги, логика библиотеки и ошибки
├── go.mod         # Модуль Go
└── main.go        # Точка входа в приложение
```
